## Getting started

1. Clone the repository:

   ```bash
   git clone https://github.com/syedasad09/Traffic-Analyzer.git
   cd Traffic-Analyzer
   ```

2. Extract the ZIP archive and open a terminal in the extracted directory.
3. Install Python 3 and review the source imports for any additional package dependencies.
4. Run:

   ```bash
   python "PM_Project - FA23 - GUI Implementation.py"
   ```

Some functionality may require a graphical desktop, OS-specific network APIs, or elevated privileges. Run this only on computers and networks you own or are authorized to assess.
